# CleanWeb iOS

iOS is planned but not implemented.

The expected platform shape is a native iOS app plus a Network Extension Packet Tunnel Provider:

```text
apps/ios/
  App/
  PacketTunnelExtension/
  Shared/
```

Work should not start here until Apple Network Extension entitlement, App Store VPN and parental-control policy, Mihomo packaging, extension memory limits, and license boundaries are confirmed.
