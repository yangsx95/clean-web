产品界面

工作方式

过滤、直连和代理由同一套策略决定

01

先判断安全规则

手动拦截、核心内容类别、恶意软件和诈骗规则先于代理路由执行。

02

再决定出口

允许的流量按路由规则走直连或代理，未命中时使用当前代理策略。

03

最后记录结果

访问日志只保存本机可观察到的最终决策，不保存代理凭据。

核心能力

为家庭设备和个人自律设计

内容过滤

基于域名、DNS 查询、IP 和 CIDR 执行本地规则，覆盖成人内容、赌博、恶意软件和诈骗风险。

安全搜索

为主流搜索服务生成安全搜索映射，并通过受控 DNS 配置应用。

规则管理

支持内置规则、外部规则源和手动规则，拦截规则与路由规则分开管理。

锁定状态

锁定后只显示运行状态和统计数字，敏感配置需要管理密码解锁。

代理节点

导入自己的订阅，保留 CleanWeb 的规则边界

CleanWeb 不提供代理节点，只导入用户自己的订阅或单节点配置。订阅中的 DNS、TUN、脚本和路由策略会被丢弃，只保留代理节点、代理组和节点关系。

二维码导入本地拖入图片解析

本地优先

配置和日志保存在你的电脑上

不托管代理

订阅地址和节点凭据只用于本机生成运行配置。

不解密 HTTPS

0.1 版本只基于可观察的域名、DNS 和 IP 做决策。

不做云同步

管理密码、规则和访问日志均在本机保存。
