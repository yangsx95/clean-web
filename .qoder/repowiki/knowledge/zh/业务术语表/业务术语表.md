### 保护开关
- 定义：CleanWeb 的全局网络保护总开关，对应数据库键 `protection_enabled`；关闭时 Mihomo 内核不启动，所有流量走 DIRECT，但产品仍保持 fail-open 行为。
- 别名：protection_enabled

### 代理开关
- 定义：是否启用 Mihomo 代理功能，对应数据库键 `proxy_enabled`；关闭时最终 MATCH 规则指向 DIRECT，不再经过 CleanWeb 代理组。
- 别名：proxy_enabled

### 安全搜索
- 定义：将 Google/Bing/DuckDuckGo/YouTube/Yandex 等搜索引擎域名强制重定向到其 SafeSearch/Restricted 目标域的能力，通过 hosts 映射与 fake-ip-filter 配合实现，可被用户订阅覆盖。
- 别名：safe-search

### 订阅
- 定义：从远程 URL 拉取并解析的规则或代理源，分为 rule（规则）、proxy（代理节点/分组）两类，支持 Clash YAML、Adblock、Hosts、IP/CIDR、DomainList、SafeSearch 等多种格式，并可设置定时刷新间隔。
- 别名：subscription

### 代理选择
- 定义：对内置 `CleanWeb` 代理组（或导入的第三方 group）手动指定当前活跃节点的持久化记录，保存在 `proxy_selections` 表中；当自动节点选择关闭时生效。
- 别名：proxy_selections

### 自动节点选择
- 定义：控制 `CleanWeb` 代理组是 `url-test`（按延迟自动挑选）还是 `select`（由用户手动指定）模式，对应数据库键 `automatic_node_selection`。
- 别名：automatic_node_selection

### 家长规则
- 定义：由管理员（家长）手工添加的精确/后缀/关键字/正则/域名/IP/CIDR 规则，优先级高于内容安全分类与订阅规则，支持 allow/proxy/block 三种动作。
- 别名：parent_rules

### 导入规则
- 定义：从第三方订阅解析出的规范化规则记录，保留来源与分类信息，按“高安全风险优先”的顺序插入到最终规则链中。
- 别名：imported_rules

### 代理载荷
- 定义：订阅下载的 Clash 代理配置经 AES-GCM 加密后存储在 `proxy_payloads` 表中的密文，解密后才用于生成 Mihomo 配置，防止明文泄露。
- 别名：proxy_payloads

### 匹配
- 定义：Mihomo 规则链末尾的兜底动作，当所有前置规则未命中时执行，根据代理开关决定走 `CleanWeb` 代理组还是 `DIRECT`。
- 别名：MATCH

### 直连
- 定义：Mihomo 规则目标之一，表示不经代理直接出站，用于局域网、Apple/Microsoft 系统服务、中国大陆 IP 等场景。
- 别名：DIRECT

### 拒绝
- 定义：Mihomo 规则目标之一，表示丢弃该连接，用于黑名单类规则。
- 别名：REJECT

### Fake-IP
- 定义：CleanWeb 使用的 DNS 增强模式，将域名解析到 `198.18.0.1/16` 网段以便统一拦截与测速，同时通过 `fake-ip-filter` 排除路由器、Windows 检测与搜索引擎域名以避免误判。
- 别名：fake-ip

### 嗅探
- 定义：Mihomo 的协议识别能力，CleanWeb 启用了 HTTP/TLS/QUIC 端口嗅探并将 `override-destination` 打开，使基于 SNI 的域名规则能正确工作。
- 别名：sniffer

### 控制器
- 定义：Mihomo 内置的本地 REST API 服务，CleanWeb 通过 `http://127.0.0.1:19090` 与其通信，用于热重载配置、查询/切换代理组、测速等。
- 别名：controller
