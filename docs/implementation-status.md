# CleanWeb 当前实现审计

审计基线：2026-07-18 当前工作区。状态只依据代码和已有自动化测试，不把界面展示或配置文本等同于真实系统能力。

状态含义：

- **已完成**：主要代码路径存在，并有相应测试或本机真实流量证据。
- **部分完成**：已有可运行路径，但缺少产品要求的一部分、可靠性闭环或跨平台验证。
- **未完成**：没有满足需求的实现。
- **冲突**：当前行为与新版产品规格相反。

## 建议实施顺序

1. 在无其他 VPN/TUN/系统代理的环境安装 v11 helper，验收系统 DNS → Xray 回环 DNS、Xray TUN → Mihomo 代理、代理端点防环路由、崩溃恢复、主动关闭和失败回滚。
2. 完成 Google/Bing/YouTube 等安全搜索真实矩阵，通过后删除 macOS 单 Mihomo TUN 的遗留 helper 请求。
3. 完成系统管理员密码重置和卸载恢复闭环。
4. 建立经许可证审核、签名、可回退的官方基础规则包和 canonical rule 来源模型。
5. 完成 macOS Universal 签名公证构建及真实网络验收矩阵，再实现 Windows Service 等价版本。
6. 启动 Android `VpnService` 原型；iOS 先验证 entitlement 再排期。
